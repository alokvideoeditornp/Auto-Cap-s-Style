Auto Cap's Style

AI-Powered Animated Captions & Subtitle Studio for DaVinci Resolve. Create viral, animated Reels, Shorts, and TikTok subtitles with 1-click timeline integration.

🌟 Key Features

⚡ 1-Click Timeline Extraction

Extracts all subtitle tracks and timings directly from your active DaVinci Resolve timeline automatically with frame-level accuracy.

✨ 10+ Pro Entrance Animations

Includes Slide Left, Slide Right, Slide Up, Pop, Fade, Typewriter, Elastic, Kinetic, Chaos, and 3-Way Focus with smooth spring physics.

🎤 Word-by-Word Karaoke

Active spoken word tracking, cumulative reveal mode, and customizable color fade transitions (Fade In & Out, Snap, and Smooth Fade).

🔤 Dual Font Engine

Independent Base Font and Highlight Font selection with individual sizing multipliers, line spacing, and letter spacing controls.

💡 Drop Shadows & Inner Glow

Configurable blur radius, shadow distance, angle offsets, opacity, and radiant glow effects for both base and highlighted words.

💎 Alpha Transparency ProRes Export

Export ultra-crisp ProRes 4444 (.mov) with 100% transparent alpha channels for instant overlay on video tracks in your timeline.

📁 Dedicated Media Pool Management

Automatically creates and manages rendered captions in the 📁Auto Caps Style bin inside DaVinci Resolve.

🖥️ Smart Responsive Studio Layout

Pure multi-panel studio layout with live Remotion canvas preview, strict 9:16 aspect ratio scaling, and mobile auto-collapse.

💻 Installation Guide (All OS)

🪟
Windows 10 & 11
  1. Install Node.js LTS from nodejs.org and Python 3.11 from python.org (Enable "Add to PATH").
  2. Copy the Auto Caps Style folder into your Fusion Scripts directory:
    C:\Users\<Username>\AppData\Roaming\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility\Auto Caps Style\
  3. Open DaVinci Resolve and go to:
    Workspace ➔ Scripts ➔ Auto Caps Style ➔ Auto Cap's Style
🍎
macOS (Apple Silicon & Intel)
  1. Install Node.js & Python 3.11 via Homebrew or official PKG installers:
    brew install node python@3.11
  2. Copy the Auto Caps Style folder into:
    ~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/Auto Caps Style/
  3. Open DaVinci Resolve and go to:
    Workspace ➔ Scripts ➔ Auto Caps Style ➔ Auto Cap's Style
🐧
Linux (Ubuntu / Arch / Fedora)
  1. Install prerequisites via terminal:
    sudo apt install nodejs npm python3.11 python3-pip
  2. Copy the Auto Caps Style folder into:
    ~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/Auto Caps Style/
  3. Open DaVinci Resolve and go to:
    Workspace ➔ Scripts ➔ Auto Caps Style ➔ Auto Cap's Style
